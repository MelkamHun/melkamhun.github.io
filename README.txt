MELKAMU HUNEGNAW ASMARE — PERSONAL ACADEMIC WEBSITE

A responsive, build-free website prepared for https://melkamhun.github.io/.
Open index.html locally to preview. No installation is needed.

PUBLISH ON GITHUB PAGES
1. Sign in to GitHub as MelkamHun.
2. Create a public repository named melkamhun.github.io.
   If that repository already exists, review its contents before uploading.
3. Upload the contents of this folder to the repository root, including assets/.
   index.html must be at the top level, not inside another folder.
4. In Settings > Pages, select Deploy from a branch, main, / (root), then Save.
5. Wait for GitHub Pages to finish deployment. The target address is
   https://melkamhun.github.io/.

EDITING
- index.html: biography, news, papers, projects, teaching and links.
- assets/style.css: layout, colours and responsive styles.
- assets/main.js: publication filtering and navigation highlighting.
- assets/melkamu-asmare.jpg: portrait from the KU Leuven eMedia profile.
- assets/Melkamu_Asmare_Academic_CV.pdf: curated public academic CV.
- Update the footer and sitemap.xml when publishing substantial changes.
- If the domain changes, update canonical and Open Graph URLs in index.html,
  plus robots.txt and sitemap.xml.

DESIGN AND CONTENT
Original implementation inspired by the academic homepage structure at
https://pituohai.github.io/. No template code or third-party theme is included.
The content uses the owner's CV and supporting documents, with institutional
profile and publication links. Project descriptions describe research aims.
No private application files, referee details, student names or funding totals
are included. The downloadable CV is a public summary, not a job application.

There are no analytics, trackers, remote fonts, frameworks or build dependencies.
Core content, links and project disclosures work without JavaScript.
